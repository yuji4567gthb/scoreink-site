プライバシーポリシー

ScoreInk ／ 制定日：2026年10月27日

ScoreInk（以下「本アプリ」）は、利用者本人が自分の楽譜を閲覧・書き込みするための個人用アプリです。本アプリにおける情報の取り扱いは次のとおりです。

1. 取得する情報

  • Googleアカウントのメールアドレス（ログイン状態の表示のため）
  • Google Driveの指定フォルダにあるPDFファイルと、その名前・フォルダ構成
  • 本アプリが作成する書き込みデータと元のPDFの控え（利用者のGoogle Driveのアプリ専用領域に保存）

2. Googleのアクセス権限と利用目的

  • Google Drive（https://www.googleapis.com/auth/drive）：指定フォルダの楽譜PDFの一覧取得・ダウンロードと、書き込みを反映したPDFの保存、ファイルの追加・名前変更・移動・削除のために使用します。
  • アプリ専用データ領域（https://www.googleapis.com/auth/drive.appdata）：端末間で書き込みを同期するためのデータと、元のPDFの控えの保存に使用します。

これらの権限は、上記の機能を提供する目的にのみ使用します。

3. 情報の保存場所

取得した情報は、利用者の端末内と、利用者本人のGoogle Driveにのみ保存されます。開発者が管理するサーバーはなく、開発者が利用者のデータを受け取ることはありません。

4. 第三者への提供

本アプリは、取得した情報を第三者に提供・販売・共有しません。広告や行動分析のためのツールも使用していません。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリによるGoogle APIから受け取った情報の利用と他のアプリへの転送は、限定的使用の要件を含むGoogle API サービスのユーザーデータに関するポリシーに準拠します。

6. データの削除

本アプリを端末から削除すると、端末内のデータは削除されます。Google Driveに保存された楽譜と書き込みデータは、利用者がGoogle Driveで削除できます。本アプリのアクセス権は、Googleアカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

7. 改定

本ポリシーを改定する場合は、このページで公開します。
